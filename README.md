# Decision Frameworks

This repository contains repeatable approaches for making architectural and organisational decisions.

Frameworks should explain how to analyse a problem, assess options and arrive at a decision. They should be reusable across organisations and domains.

Examples:

- [Information Accountability](https://github.com/Mutual-Bootstrap/decision-frameworks/blob/main/Information%20Accountability.md)
- [Business Object Identification](https://github.com/Mutual-Bootstrap/decision-frameworks/blob/main/Business%20Object%20Identification.md)
- Capability Ownership
- Decision Accountability

If a document answers the question *"How should we decide?"*, it probably belongs here.
